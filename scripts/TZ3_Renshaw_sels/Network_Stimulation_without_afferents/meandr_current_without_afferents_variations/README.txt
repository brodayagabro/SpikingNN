Система моделирования нейромышечной системы с импульсными воздействиями. Исследование влияния клеток Рэйншоу на сеть центрального генератора ритма.

Подготовка симуляции: gen_cfg_meandr_pulse_without_afferents_rainshow_sells.py

В файле gen_cfg_meandr_pulse_without_afferents_rainshow_sells.py формируется полная таблица параметров (cfg.csv), по которой в дальнейшем проводятся вычислительные эксперименты основываясь на конфигурационном файле config.json:
{
  "archive_name": "data_meandr_pulses_without_afferents_rainshow_weights",
  "output_filename": "cfg.csv",
  "base_weight": 0.5,
  "renshaw_weights": {
    "min": 0.0,
    "max": 1.0,
    "step": 0.9
  },
  "meander": {
    "period": {"min": 300, "max": 300, "num": 1},
    "duration_flex": {"min": 100, "max": 100, "num": 1},
    "duration_ext": {"min": 100, "max": 100, "num": 1},
    "amplitude_cpg_in": {"min": 5.0, "max": 5.0, "num": 1},
    "amplitude_cpg_n": {"min": 6.5, "max": 6.5, "num": 1},
    "phase_flex": {"min": 0.1, "max": 0.1, "num": 1},
    "phase_ext": {"min": 0.6, "max": 0.6, "num": 1}
  },
  "base_currents": [0, 0, 0, 0],
  "noise_percent": 0.05
}

Каждая строка этой таблицы задаёт одну уникальную конфигурацию модели нейромышечной системы, включающую параметры импульсной стимуляции, синаптические веса и метаданные.

Цель исследования

Цель исследования заключается в изучении влияния импульсных стимуляций и асимметрии в связях с клетками Рэншоу на динамику ритмической активности центрального паттерн-генератора (ЦПГ) и связанной с ним периферической системы.

Рассматриваемые нейронные связи с клетками Renshaw (Rainshow):

ОТ клеток Renshaw (6 связей):
R_Flex->Ia_IN_Flex
R_Flex->MN_Flex
R_Flex->R_Ext
R_Ext->Ia_IN_Ext
R_Ext->MN_Ext
R_Ext->R_Flex

К клеткам Renshaw (2 связи):
MN_Flex->R_Flex
MN_Ext->R_Ext

Всего 8 синаптических связей затрагивают клетки Рэншоу. В эксперименте варьируются веса этих связей для изучения влияния реципрокного торможения между R_Flex и R_Ext на паттерны мышечной активности.

Параметры импульсной стимуляции

Для каждого из четырёх входных каналов задаются следующие параметры:
- Период импульсов (мс) - интервал между началами последовательных импульсов
- Длительность импульсов (мс) - продолжительность каждого импульса
- Амплитуда импульсов - величина тока во время импульса
- Фаза импульсов - сдвиг относительно начала периода в долях (0-1)
- Базовый постоянный ток - фоновый ток

Каналы 0 и 2 (Flex group) имеют одинаковые параметры импульсов, как и каналы 1 и 3 (Ext group), что позволяет исследовать взаимодействие двух групп импульсных воздействий.

Режимы соотношения весов связей
Все веса клеток Рэйншоу перебираются с шагом 0,25 от 0 до 1

Параметры симуляции
В ходе визуального анализа при всех связях сети 0.5 происходил поиск параметров, когда мышцы находятся в противофазной синхронизации.
Общая длительность: 10 секунд (10000 мс)
Частота дискретизации: 5 точек/мс (шаг интегрирования 0.2 мс)
Уровень шума: 5% (гауссовский шум, стандартное отклонение = 5% от базового тока)
Базовые токи: [0, 0, 0, 0]
Амплитуды: Каналы 0,2: 5.0; Каналы 1,3: 6.5
Период импульсов: 300мс
Длительность импульсов: 100мс
Фаза флексорного полуцентра: 0.1
Фаза экстензороного полуцентра: 0.6

Вычисление метрик: feature_extractor.py

В файле feature_extractor.py реализованы алгоритмы извлечения признаков из временных рядов. Вычисляются следующие метрики:

Нейронная активность (для каждого из 12 нейронов):
- Среднее значение мембранного потенциала (V)
- Стандартное отклонение мембранного потенциала
- Частота спайков (spikes/sec)
- Коэффициент вариации межспайковых интервалов (CV of ISI)

Мышечные силы (Flexor и Extensor):
- Среднее, максимальное, минимальное значение силы
- Стандартное отклонение силы
- Частота колебаний силы (доминирующая частота через FFT)
- Коэффициент вариации силы

Соотношения и корреляции:
- Среднее соотношение сил Flexor/Extensor
- Коэффициент корреляции Пирсона между силами мышц
- Коэффициент корреляции между углом и угловой скоростью конечности

Кинематические метрики:
- Средний, максимальный, минимальный угол конечности
- Стандартное отклонение угла
- Средняя угловая скорость и её стандартное отклонение

Афферентная активность (6 каналов):
- Статистики для каждого афферентного канала (Ia, II, Ib для Flex и Ext)

Классификация режима работы:

На основе вычисленных метрик система классифицируется в один из режимов:
- Стабильный синхронный: низкая вариативность, синфазная активность мышц
- Ритмический: периодические колебания с чёткой доминирующей частотой
- Кластерный: группировка спайков в кластеры с регулярными интервалами
- Хаотический: высокая вариативность, отсутствие доминирующей частоты
- Стабильный нейронный: нейроны активны, мышцы статичны
- Ритмический нейронный: ритмическая активность только на уровне нейронов
- Хаотический нейронный: нерегулярная активность нейронов без мышечного ответа

Запуск симуляций: calc_meandr_pulse_without_afferents.py

Основной файл программы выполняет следующую последовательность этапов:

1. Загрузка конфигурации из cfg.csv
2. Инициализация модели нейромышечной системы (сеть Рыбака + мышцы + механика конечности)
3. Для каждой конфигурации:
   - Установка синаптических весов для целевых связей
   - Генерация импульсного входного тока (4 канала)
   - Запуск симуляции на 10 секунд
   - Обрезка первых 50% данных (исключение переходных процессов)
   - Извлечение признаков через feature_extractor.py
   - Сохранение временных рядов мышц в CSV-файлы (папка data/)
   - Добавление вычисленных метрик в итоговую таблицу
4. Сохранение результатов в корневой директории проекта

Параллельные вычисления

Скрипт использует joblib.Parallel для параллельного запуска симуляций на всех доступных ядрах CPU (n_jobs=-1).

cfg.csv - Таблица конфигураций

Колонки:
- combination_id: уникальный идентификатор конфигурации
- target_pair: название целевой пары нейронов
- pulse_period_ch0-3: период импульсов для 4 каналов (мс)
- pulse_duration_ch0-3: длительность импульсов для 4 каналов (мс)
- amplitude_ch0-3: амплитуда импульсов для 4 каналов
- phase_ch0-3: фаза импульсов для 4 каналов (доли периода)
- base_current_I1-4: базовый ток для 4 каналов
- noise_percent: уровень шума (0.05 = 5%)
- <source>-><target>: веса синаптических связей (26 колонок)

experiment_results_meandr_pulse_without_afferents.csv - Итоговые результаты

Содержит все исходные параметры из cfg.csv плюс следующие дополнительные поля:

Статус:
- status (success/error)
- muscle_csv_file (имя файла с временными рядами)

Режим:
- mode (классификация режима работы)

Нейроны:
- V_mean_N0-11, V_std_N0-11
- spike_rate_N0-11, cv_isi_N0-11

Мышцы:
- F_flex_mean, F_flex_max, F_flex_min, F_flex_std, F_flex_freq, F_flex_cv
- F_ext_mean, F_ext_max, F_ext_min, F_ext_std, F_ext_freq, F_ext_cv

Соотношения:
- F_ratio_mean, F_correlation, Q_W_correlation

Кинематика:
- Q_mean, Q_max, Q_min, Q_std
- W_mean, W_std

Афференты:
- Aff_mean_ch0-5, Aff_std_ch0-5, Aff_freq_ch0-5

Файлы в data/

Каждый файл имеет формат CSV с тремя колонками:

t - время (мс)
F_flex - сила флексорной мышцы (а.е.)

Пример имени файла: meandr_pulses_without_afferents_a3f2b1c8_muscles.csv

Быстрый старт

пайплайн: run.sh - запускает генерацию параметров симуляций по config.json, далее производит симуляции. После окончания симуляций сжимает папку data с временными рядями мышц. Если скрипт был запущен с ключами --cleanup|-c то после архивирования папка будет автоматически стерта. Архив сохранится на директорию выше с названием указанным в config.json/

Примечания

- Временные ряды обрезаются на 50% для исключения переходных процессов (первые 5 секунд отбрасываются)
- Шум добавляется к базовому току на каждом шаге интегрирования
- Веса связей вне целевой пары фиксируются на значении 0.5
- Афферентная обратная связь: Ia->CPG_In(w=10)

# Тетрадки

[training_phase_trajectories.ipynb](training_phase_trajectories.ipynb) показывает
настоящие траектории сохранённых особей: полные Afferents, шаг 0.1 мс,
момент без ×10 и нейронный режим 0.

## Запуск

```bash
.venv/bin/jupyter lab scripts/AfferentBalance2026/notebooks/training_phase_trajectories.ipynb
```

Выберите ядро `SpikingNN (.venv)` и выполните ячейки сверху вниз. Репозиторий
находится по `src/SpikingNN/core/Izh_net.py`. `runtime_support.current_results()`
читает указатель `../report/results/current_unscaled.json`. Для другой серии
задайте `ROOT` явно до вызова `runtime_directory(ROOT)`.

Тетрадка загружает исходный `factor_1/runtime`, проверяя его SHA-256. Старое
имя пакета внутри снимка сохраняется, внешний путь после переименования
разрешается автоматически. При уже импортированной другой численной версии
перезапустите kernel. Зависимости: `../requirements-notebook.txt`.

## Возможности

- Кривые fitness и успешности, сравнение нескольких поколений.
- Лидер или до пяти лучших особей по training выбранного поколения.
- Отдельно — реальный победитель validation последнего завершённого среза;
  его training-ранг вычисляется только для доступа к той же особи.
- Старты ±8°, ±45° и смешанный набор с ненулевыми скоростями.
- Разные целевые углы и пять далёких стартов для законов токов.
- Фазовые траектории θ–ω, угол во времени, метрики и ранние падения.
- Собственный `CASES`: `[target,theta0,omega0,kick_t,kick_dw]`, радианы и секунды;
  `kick_t=-1` отключает толчок.

Для баланса цель равна нулю и внешних токов нет. Для заданного угла ток
вычисляется из сохранённого закона и постоянен во времени. Он не содержит
сигнала ПД. Перед каждым стартом скрытые состояния сбрасываются одинаково.
Кривые получаются интегрированием полной системы, без интерполяции геномов.

Выбор по training и validation различается; поколения не задают одну
наследственную линию. Штрафная поздняя RMSE при падении равна 90° и не является
измеренной установившейся ошибкой.

## Код и файлы

[phase_viewer.py](phase_viewer.py) содержит каталог, воспроизведение, виджеты,
рисование и экспорт. [training_history.py](../experiments/core/training_history.py)
задаёт формат поколений. Чистая исходная тетрадка редактируется непосредственно;
отдельного `build_training_phase_notebook.py` в рабочем каталоге нет.

Срезы sweep `epochs_*/generations/` объединяются в историю 1…200. Во время
обучения можно повторно выполнить ячейки каталога и виджетов; незавершённые
атомарные записи пропускаются. Экспорт идёт в `notebook_exports/` выбранной
серии: PNG/PDF, полные NPZ, CSV метрик, JSON с хешем исходного поколения.
Эти файлы игнорируются Git; исходная тетрадка не содержит выводов.

[Полный пересчёт](../experiments/RECOMPUTE_UNSCALED.md).
Историческая `../report/edit_figures.ipynb` сохранена с очищенными выводами;
её данные ×10 находятся в корзине, она не является актуальным просмотрщиком.

# Configuration reference

[Русский](CONFIGURATION.md) · [Guide](USER_GUIDE.en.md)

Generated by `python tools/check_workflow.py --write-docs`; checked by `--check-docs`.
Run schema: `afferent_experiment_run_v1`. Exactly one local versioned preset is merged with the JSON request,
then explicit CLI overrides. Arrays replace their entire previous value. No arbitrary inheritance chain is supported.
A fully resolved saved config is accepted as a standalone domain. Unknown or misplaced keys are errors.
Paths in JSON are relative to the declaring file; CLI paths are relative to cwd.
Leaf origins and original/resolved paths are recorded in `provenance`.

The table lists actual preset values. Empty task blocks are inapplicable; D requires explicit source paths.
Finetune without config uses its saved physical domain and explicit warm defaults described in the guide.
Prepare operations are allowed only in prepare/validate, not inherited silently into training.

`genome.parameters` contains exactly the named controller schema in the preset, with `index`, `name`, `value`,
`minimum`, `maximum`, `scale`, `mutable`, `unit`, `description`, and `system_parameter`.
`genome.overrides.<exact name>` accepts value/mutable/minimum/maximum/scale only. Fixing requires value;
freeing a previously fixed gene requires both bounds and scale. Geometry remains fixed. Mirror pairs require matching domains.
Controller and run schemas have separate versions. Structural network changes require a new codec/model, not extra JSON fields.

`search.generations` is the total C staged budget and the per-branch D comparison budget.
`table_generations=null` assigns floor(total/2). `search.checkpoints` never restarts a GA.
`sweep.axes` accepts nonempty unique arrays of population/generations/seed/mutation_probability/method/degree;
each combination is an independent line. Validation lists the expanded budgets.
`coefficient_bound_nA` limits individual coefficients; `table_current_bound_nA` limits table entries.
`storage.recording_stride` is a positive integer; metrics always use the 0.1 ms step.

The command defaults are defined by the parser, while scientific defaults come from these presets.
Use `validate --json` for exact values, sources, fixed fields, dimensions, banks and selection policy.

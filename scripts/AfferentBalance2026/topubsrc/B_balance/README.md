# Эксперимент B: Удержание верхнего равновесия при ограниченных мышечных весах

Два мотонейрона, нулевые внешние токи, мышечные веса `0,02 <= w < 0,1`. Обучение совместное (`joint`).

Все команды ниже выполняются **из родительской папки `topubsrc`**, а не из `B_balance`. Из этой папки сначала выполните `cd ..`. Окружение и полный алгоритм описаны в [общем README](../README.md).

```bash
python -m pip install -r requirements-reproducible.txt
python run.py check B --profile fast

# Проверка плана: 9 размеров × 9 бюджетов × 2 seed = 162 запуска.
python run.py grid --experiments B --population-range 10 50 5 --generation-range 100 500 50 --seeds 42 43 --mutation-probability 0.3 --jobs 2 --workers 10 --output results/B_grid_20261117 --plan-only

# Полная сетка этого эксперимента, обучение с нуля:
python run.py grid --experiments B --population-range 10 50 5 --generation-range 100 500 50 --seeds 42 43 --mutation-probability 0.3 --jobs 2 --workers 10 --output results/B_grid_20261117

# Состояние и текущие лучшие гиперпараметры:
python run.py status --output results/B_grid_20261117

# Отдельный поиск с указанными гиперпараметрами:
python run.py train B --profile fast --population 30 --generations 300 --seed 42 --mutation-probability 0.3 --workers 10 --output results/B_N30_G300_seed42
```

В текущем расчёте B и C объединены одной командой `grid --experiments B C` в `results/bc_grid_20261117`; для проверки именно этой очереди используйте `python run.py status --output results/bc_grid_20261117`. Отдельная команда выше воспроизводит только B. Совместный и отдельный варианты не нужно запускать одновременно для одной и той же сетки.

Оси сетки: популяции 10…50 с шагом 5, поколения 100…500 с шагом 50, seed 42 и 43, p=0,3. `--jobs` задаёт число независимых поисков одновременно, `--workers` — потоки Numba на поиск. Каталог результата должен быть новым. Инициализация: одна общая особь, `max(1,M//4)` равномерных особей, остальные — гауссовы отклонения σ=0,1 с отражением в [0,1]. Начальных архивных контроллеров нет.

Область генома: четыре веса от афферентов II в ±50; обе мышечные N изменяемы в [1,40]; перекрёстные P строго <0,1. Лимит частоты — каждый ISI ≥10 мс на всём эпизоде. Нарушение получает отрицательную оценку; уравнения нейронов не меняются. Динамика: 10 с, окно точности: последние 2 с. Параметры находятся в `genome_cfg.json`, профили — в `profiles.json`, базовые настройки обучения — в `training.json`.

Лучшие геномы сохраняются **во время обучения**: `training/best_genome.json` для B, `table/best_genome.json` и `polynomial/best_genome.json` для staged C. Каждый новый рекорд по валидации сохраняется ещё и как `best_genomes/gXXXX_genome.json` внутри соответствующей стадии; `selection.json` содержит гиперпараметры, путь и хеш. Поколение 0 сохраняется сразу, последующие проверки — на 1-м, каждом 20-м и последнем поколении стадии. Все улучшения перечислены в `best_history.csv`.

`leaderboard.json/csv/md` в корне сетки показывает лидеров и настройки поиска; `comparison.csv/json` и `RESULTS.md` — все завершённые запуски с train/validation/test. Промежуточный лидер помечен как `running`, итоговый — `completed`. Выбор выполняется по валидации; test не влияет на отбор. Для C в общий рейтинг входит только полиномиальная стадия. JSON-список `completed_leaders` позволяет отдельно посмотреть победителей только среди завершённых запусков.

После завершения допустимый на валидации победитель этой сетки появится в `genomes/fast_grid_rate100.json`. Загрузка динамики:

```bash
python run.py simulate B --genome B_balance/genomes/fast_grid_rate100.json --angle -30 --target 0 --output results/B_grid_replay
```

В `explore.ipynb` можно указать тот же путь в `GENOME_PATH` или путь к промежуточному снимку. Каждый сохранённый геном содержит свою конфигурацию.

## Тестирование итогового генома полной сетки

Выбран по валидации запуск с популяцией 35, бюджетом 450 поколений, seed=42 и p=0,3; лучший геном найден на поколении 440. На тесте fitness=0,794326, все 96/96 эпизодов выдержали 10 с, строгий успех — 0/96. Средняя поздняя RMSE составляет 0,582°. Основное нарушение критерия — скорость: во всех 96 случаях после 3 с есть выходы за |ω|≤0,35 рад/с; максимальная скорость в последние 2 с составляет 1,52–1,63 рад/с. Оба нейрона активны в каждом позднем секундном интервале всех тестов; средние поздние частоты около 12,85 Гц, максимальные мгновенные — менее 30 Гц. Лимит 100 Гц соблюдён во всех 96 тестах.

Команды из `topubsrc`:

```bash
# Повтор всех 504 тестовых эпизодов экспортированных B и C, без обучения:
python verify.py --catalogue results/bc_grid_20261117/published_results.json --workers 8

# Все тесты B с полным подсчётом спайков и проверкой сохранённых метрик:
python run.py activity --run results/bc_grid_20261117/expanded_B/G450/N35_p0.3_seed42
```

`verify.py` заново формирует test-банк из сохранённой конфигурации, рассчитывает динамику и сравнивает её метрики с зафиксированными массивами. `status: passed` относится к воспроизводимости; поле `success` сообщает число эпизодов, прошедших критерий управления. Для этих геномов повтор всех 504 эпизодов дал нулевое расхождение метрик, но строгий успех остаётся нулевым.

`activity` отдельно пересчитывает тестовые эпизоды B с шагом записи 0,1 мс, проверяет метрики и сохраняет частоты, минимальные ISI и нарушения в `results/bc_grid_20261117/expanded_B/G450/N35_p0.3_seed42/activity.json`. Данные качества — в соседнем `result.json`. Успех требует удерживать ошибку в пределах ±3° и |ω|≤0,35 рад/с с 3-й секунды до конца 10-секундного эпизода, а также соблюдать ограничение частоты.

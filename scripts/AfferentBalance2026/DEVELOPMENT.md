# Разработка и проверка

[English](DEVELOPMENT.en.md) · [Обзор](README.md)

Из корня репозитория:

```bash
.venv/bin/python -m pytest -c scripts/AfferentBalance2026/pytest.ini scripts/AfferentBalance2026/tests -q
.venv/bin/python scripts/AfferentBalance2026/validate_layout.py
```

Тесты сопоставляют Numba с независимым воспроизведением классами библиотеки, проверяют нелинейные рецепторы, все 52 поля и фиксированную геометрию, английские описания, ограничения A/B, банки условий, воспроизводимость процессного пула, сохранение поколений/победителей и sweep. Короткие реальные интегрирования служат проверкой реализации, не результатом научного обучения. Архивные тесты исключены из активного сбора.

Тетрадки используют ядро `spikingnn`. Переменная окружения `SPIKINGNN_NOTEBOOK_SMOKE=1` сокращает их демонстрационные сетки и горизонт для автоматической технической проверки; обычный запуск использует полные значения. Обучение в тетрадках выключено до явного изменения флага.

Изменяйте общую физику только в `experiments/simulation.py` и проверяйте соответствие `SpikingNN.core.Izh_net` по всем каналам. Изменения закона токов относятся только к C. Докстроки и комментарии нового кода, описания полей JSON — английские; документация имеет пару RU/EN. Результаты и снимки исходников не добавляйте в Git.

Старые числовые массивы нельзя интерпретировать по новому порядку полей. Не редактируйте runtime внутри исторических результатов и не заменяйте записанные там хеши новыми. Исторический и текущий runtime проверяются в разных процессах.

## Проверено 20 октября 2026

37 тестов прошли. Все три `explore_genome.ipynb` выполнены ядром `spikingnn` в сокращённом режиме (0,02 с). Отдельно проверены CLI A, sweep B и сетка C из `/tmp`, включая два процесса для A (эпизоды 0,01 с). Хеши исторического runtime ×1 совпали с сохранёнными. Научные обучения по новому протоколу не запускались.

## Проверено 21 октября 2026

Все 41 тест прошли. Добавлены проверки полного диапазона начальных условий, несимметричных диапазонов и нечётного размера банка, а также совпадения Numba с библиотекой для случайных допустимых геномов. Все три тетрадки повторно выполнены в сокращённом режиме с фактически сохранёнными лучшими геномами; записи находятся в `results/notebook_validation.json`. Обучение при проверке тетрадок не запускается.

Научные серии A/B завершены: по 12 непрерывных обучений, 60 контрольных точек и 2400 сохранённых поколений. `analyze_abc_study.py` проверил все популяции, допустимость генов, фиксированные `a1/a2`, воспроизведение фитнесса и хеши исходников. Выбор выполнен по валидации, затем независимо пересчитан тест победителя. В каждом опыте записаны 110 диагностических траекторий. C записал 550 траекторий без подбора токов. Подробности — в локальных `results/README.md` и `audit.json` для A/B.

Дополнительно сопоставлена одна секундная траектория обученного A с исходными классами `SpikingNN.core.Izh_net`: начальные условия +50°, +1 рад/с, 10001 отсчёт, все 26 каналов. Максимальное абсолютное расхождение — около `4.19e-12`; использованный геном и его хеш указаны в `experiments/A_balance/results/model_reference_check.json`. Это проверка численной реализации, а не доказательство устойчивости на бесконечном горизонте.

Старые численные результаты перенесены в системную корзину; журнал — `archive/cleanup_results_20261021.json`. Исходники исторического протокола сохранены. Новые результаты исключены из Git.

# Разработка и проверка

[English](DEVELOPMENT.en.md) · [Обзор](README.md)

Из корня репозитория:

```bash
.venv/bin/python -m pytest -c scripts/AfferentBalance2026/pytest.ini scripts/AfferentBalance2026/tests -q
.venv/bin/python scripts/AfferentBalance2026/tools/validate_layout.py
```

Тесты сопоставляют Numba с независимым воспроизведением классами библиотеки, проверяют нелинейные рецепторы, все 52 поля и фиксированную геометрию, английские описания, ограничения A/B, банки условий, воспроизводимость процессного пула, сохранение поколений/победителей и sweep. Короткие реальные интегрирования служат проверкой реализации, не результатом научного обучения. Архивные тесты исключены из активного сбора.

Тетрадки используют ядро `spikingnn`. Переменная окружения `SPIKINGNN_NOTEBOOK_SMOKE=1` сокращает их демонстрационные сетки и горизонт для автоматической технической проверки; обычный запуск использует полные значения. Обучение в тетрадках выключено до явного изменения флага.

Изменяйте общую физику только в `experiments/simulation.py` и проверяйте соответствие `SpikingNN.core.Izh_net` по всем каналам. Изменения закона токов относятся к C/D; потоковый интерфейс и сигналы находятся в D. Докстроки и комментарии нового кода, описания полей JSON — английские; документация имеет пару RU/EN. Результаты и снимки исходников не добавляйте в Git.

Старые числовые массивы нельзя интерпретировать по новому порядку полей. Не редактируйте runtime внутри исторических результатов и не заменяйте записанные там хеши новыми. Исторический и текущий runtime проверяются в разных процессах.

## D: потоковый интерфейс, 23 октября 2026

Все 66 тестов проходят, включая 10 новых проверок D (с параметризацией). `simulation.py` теперь предоставляет один физический шаг с полным состоянием: его используют прежний эпизодный решатель и потоковый D. Сохранённый 10-секундный пример C (100001 отсчёт × 26 каналов) и его метрики воспроизведены побитово. Независимая библиотека проверена также при переменных токах.

D проверяет непрерывность при разбиении на блоки, смену команд без reset, единицы фильтра, производную целевой траектории, метрики из полной записи, независимость банков, сохранение обеих схем обучения, неизменность фиксированных A/геометрии, нижнюю границу времён 5,1 мс и равенство последовательного/параллельного расчёта. Технический полный запуск с короткими эпизодами выполнен отдельно от научной серии.

Научная серия D завершена и независимо проверена: 160 поколений, 4800 особей, 81 полная траектория (34 012 998 отсчётов). `experiments/D_trajectory/audit_trajectory.py` проверяет источники, границы, все оценки и валидационный выбор, затем повторяет независимые тесты. Динамика с переменными токами сверена с библиотекой на 4,1 с у трёх решений, максимальное расхождение ≤5,83e−11. Записи — в `D_trajectory/results/trajectory_sweep_20261023/audit.json`. Итоговая тетрадка выполнена ядром spikingnn без обучения и изменения исходного ipynb.

Проверка активной структуры: `tools/validate_layout.py --allow-notebook-outputs`. Флаг позволяет проверить ссылки и код без удаления пользовательских выводов A; строгий режим по умолчанию по-прежнему требует пустых outputs. Проверены все четыре опыта, 11 пар RU/EN, английские docstring и описания генома.

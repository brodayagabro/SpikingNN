# Общее ядро

[English](README.en.md) · [Структура и результаты](../README.md)

Опциональное ограничение `mirror_symmetry` связывает отражённые пары и уменьшает
число свободных координат контроллера до 24. [Правила и опыт C/D](../MIRROR_SYMMETRY.md).
Геометрические `a1` и `a2` не приравниваются. Старые конфиги без флага совместимы.

- `genome.py`: версия `afferent_controller_52_v4`, именованные поля, проверка границ, преобразование свободные координаты→52, сохранение и явный импорт старых геномов.
- `fitness.py`: общая агрегация метрик сценариев.
- `evolution.py`: отбор турнирами, элитизм, скрещивание, мутация, наблюдатели эпох.
- `run.py`: пакетная оценка, процессный пул, обучение A/B, контрольные точки, сохранение лучших и sweep.

Динамика импортируется непосредственно из `experiments/simulation.py`. Задающие токи могут быть явно переданы общей функции оценки как массив `(особи, сценарии, 2)`; ядро не вычисляет их зависимость от целевого угла. Обучение A/B всегда использует нулевые токи. Закон токов и его отдельный подбор находятся в C.

`GenomeConfig` получает путь к JSON или словарь. `decode` вставляет фиксированные значения после генетических операций, `encode` отвергает несовпадающую геометрию и выход за границы. Изменяйте `a1`, `a2` в конфиге до запуска; они сохраняются в каждом физическом геноме, но никогда не мутируют.

C добавляет гены задания в собственном `joint_study.py`: 48 свободных параметров контроллера и восемь коэффициентов кубического закона. Напрямую переиспользуются `optimize` и `PopulationEvaluator`; каждая особь передаёт свои постоянные токи для каждого целевого эпизода. Core не интерпретирует коэффициенты закона токов.

# C_setpoint_balance: удержание заданного угла

[English](README.en.md) · [Структура](../README.md) · [Модель](../MODEL_METHODS.md)

Этот опыт использует фиксированный 52-параметрический геном. Токи не являются генами и задаются отдельно. `run_experiment.py` и `run_sweep.py` **не запускают обучение**: первый воспроизводит один набор условий, второй — сетку условий для пяти целей −45°, −22.5°, 0°, 22.5°, 45°.

```bash
.venv/bin/python scripts/AfferentBalance2026/experiments/C_setpoint_balance/run_experiment.py --genome /path/to/best_genome.json --targets 22.5 --angles -50 0 50 --speeds 0 --currents 100 80
.venv/bin/python scripts/AfferentBalance2026/experiments/C_setpoint_balance/run_sweep.py --genome /path/to/best_genome.json --current-law /path/to/current_law.json
```

Пример токов 100/80 иллюстрирует интерфейс, а не успешное решение. Без `--genome` используется необученный геном конфига. Геометрия, механика и границы загруженного решения должны соответствовать конфигу C. Сетка по умолчанию 10×10 (−50…50°, −1…1 рад/с) для каждой цели. `--currents` и `--current-law` взаимоисключающие. Углы CLI — градусы от вертикали, скорость — рад/с.

`polynomial_study.py` содержит закон `I_i(target)=Σ c_ik (target/45°)^k`: постоянный, квадратичный или кубический. Вычисленные токи постоянны внутри эпизода; измеренные угол и скорость не используются для ПД-регулирования. `load_current_law` допускает исторические файлы коэффициентов; это не импорт исторического генома.

Сохранён отдельный явно вызываемый API `fit_current_law`: подбирает только коэффициенты на переданных пользователем независимых банках, сеть фиксирована. Ни скрипты, ни тетрадка не вызывают этот подбор автоматически. Его результаты имеют отдельный формат `final_coefficients.npz`; они не выдаются за популяцию 52-параметрических геномов.

Результаты воспроизведения: `genome_cfg.json`, `best_genome.json` (именно переданный фиксированный контроллер, без отбора), `run.json`, `source_snapshot.zip`, `result.json`, `traces/case_XXX.npz`, `traces/metrics.csv`. Полный шаг записи 0,1 мс. Каждая траектория содержит цель, начальные условия и токи; `training_performed=false` явно указан. Тетрадка строит состояния одного примера и фазовые портреты по целям; `PLOT_ALL_TARGETS` включает все пять целей.

## Проверка серии 21 октября

`../../analyze_abc_study.py C_setpoint_balance` использует `A_balance/results/best_genome.json`, выбранный по валидации. Сохраняются 550 полных траекторий в `results/replay_20261021/`, сводка по пяти целям и многопанельные рисунки `target_*/multipanel.png`. Токи берутся из конфига (сейчас `[0, 0]`); это контроль без обучения закона токов. При нулевых токах разные цели изменяют только оценку одной и той же динамики. Подбор закона токов остаётся отдельным явно запускаемым опытом.

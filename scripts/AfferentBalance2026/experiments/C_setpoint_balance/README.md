## Геном и параметры

Физический блок системы сохраняет 52 поля и прежний порядок. В C фиксированы `a1`, `a2` и оба мышечных `A=0.37`; свободны 48 параметров системы. Сохранены прежние ограничения C для весов: `0.0001 ≤ w ≤ 1`. Все параметры и английские описания находятся в `genome_cfg.json`; описания добавленных командных генов также включаются в сохраняемый геном.

Для `x=target_deg/45` полином задаётся как `I_i(x)=c_i0+c_i1*x+c_i2*x²+c_i3*x³`. Постоянный член также обучается.

| Представление команды | Физических полей | Свободных координат |
|---|---:|---:|
| Квадратичный полином, 2×3 коэффициента | 58 | 54 |
| Кубический полином, 2×4 коэффициента | 60 | 56 |
| Таблица токов для пяти целей, 2×5 значений | 62 | 58 |

Коэффициенты по умолчанию ограничены ±1000 нА; табличные токи — также ±1000 нА. Это **разные ограничения**: сумма членов полинома может выйти за ±1000 нА. Токи не обрезаются; график `current_law.png` показывает фактическую команду на всём интервале. Нормированные координаты всех изменяемых генов находятся в [0,1]. Масса и остальные механические параметры — гиперпараметры вне хромосомы.

По умолчанию начальная особь берёт контроллер из `../B_balance/results/best_genome.json` и нулевую команду. Остальная популяция содержит возмущённые особи и случайных иммигрантов. Далее сеть и команда изменяются совместно. Исходный геном проверяется по геометрии, A, механике и границам без подрезания значений. `--from-scratch` исключает старт из B; `--seed-genome` выбирает другой допустимый 52-полевой контроллер.

## Банки и отбор

Каждая особь проходит **все пять целей**: −45°, −22.5°, 0°, +22.5°, +45°. Для каждой цели используются одинаковые восемь начальных условий: всего 40 учебных эпизодов на особь. Начальные углы абсолютные, −50…+50°, скорости −1…+1 рад/с; они не отсчитываются от цели. Каждый эпизод начинается с нового состояния нейронов и мышц, поэтому это удержание отдельных команд, а не переключение целей во времени.

- Обучение: 5 целей × 8 начальных условий = 40 эпизодов.
- Валидация полинома: 9 целей с шагом 11.25° × 12 независимых условий = 108 эпизодов.
- Финальный тест: 17 целей с шагом 5.625° × 24 новых условия = 408 эпизодов. Восемь тестовых целей не используются ни при обучении, ни при валидации.

Все цели имеют одинаковый вес по числу эпизодов. Используется прежняя робастная агрегация фитнесса с вкладом худших случаев; отдельно сохраняется качество каждой цели и худшая доля успеха по целям. Учебный, валидационный и тестовый банки не пересекаются. Эпизод длится 10 с; сокращённый `--duration` предназначен для технических проверок.

Выбор выполняется по валидации среди контрольных точек, включая первую эпоху и последнюю. Первая эпоха содержит стартовую особь, что позволяет сохранить хороший результат МНК, даже если последующий учебный отбор его потеряет. В сравнительной серии независимый тест рассчитывается **только для общего победителя**. Тест не выбирает метод, степень полинома или параметры ГА.

## Два пайплайна

**`joint`**: с первой эпохи обучаются параметры общей сети и коэффициенты полиномов. Это основной прямой вариант.

**`staged`**:

1. Совместно обучаются одна общая сеть и десять токов для пяти целей. Сеть одна для всей таблицы; контрольные точки этого этапа оцениваются на тех же пяти целях с независимыми начальными условиями.
2. Таблица победителя аппроксимируется двумя полиномами через ограниченный МНК (`scipy.optimize.lsq_linear`). Сохраняются ошибка аппроксимации, исходные токи и коэффициенты.
3. Полученная сеть с полиномом становится начальной особью совместного дообучения. Валидация уже включает промежуточные цели.

МНК минимизирует ошибку токов, а не ошибку движения. Даже небольшое изменение тока может изменить спайковый режим, поэтому результат МНК обязательно проходит новые динамические симуляции. Табличный геном нельзя применять к промежуточной цели без перехода к полиному.

`--generations 200` задаёт **общий** бюджет: у staged по умолчанию 100 эпох таблицы + 100 эпох полинома; у joint — 200 эпох полинома. Число учебных симуляций одинаково при одинаковой популяции. Валидационные расходы отличаются и сохраняются в метаданных. Для отдельного staged-запуска граница этапов задаётся через `--table-generations`.

## Команды

Из корня репозитория:

```bash
# Прямое совместное обучение.
.venv/bin/python scripts/AfferentBalance2026/experiments/C_setpoint_balance/run_experiment.py --mode joint --degree 3 --population 50 --generations 200 --workers 8

# Таблица -> МНК -> совместное дообучение, тот же общий бюджет.
.venv/bin/python scripts/AfferentBalance2026/experiments/C_setpoint_balance/run_experiment.py --mode staged --degree 3 --population 50 --generations 200 --workers 8

# Сравнение двух методов и двух степеней, тест только победителя.
.venv/bin/python scripts/AfferentBalance2026/experiments/C_setpoint_balance/run_sweep.py --mode compare --degrees 2 3 --populations 30 --probabilities 0.1 --seeds 42 --generations 200 --workers 8

# Полная фазовая сетка 10×10 для каждой из пяти целей из совместного генома.
.venv/bin/python scripts/AfferentBalance2026/experiments/C_setpoint_balance/run_sweep.py --mode replay --genome /path/to/joint/best_genome.json
```

По умолчанию режим `replay`, поэтому открытие тетрадки или прежние команды не запускают обучение. `--output` должен указывать новый каталог. Настройки целей и банков задаются в конфиге, а не через replay-параметры CLI. Для старого 52-полевого решения доступны `--current-law` и `--currents`; совместный геном уже содержит команду, и повторно задавать её не следует.

`explore_genome.ipynb` загружает совместный JSON, сохранённую популяцию или эпоху через `load_joint_solution`. Рейтинг эпохи — учебный; последней популяции — валидационный. При изменении цели автоматически пересчитываются токи. Доступны фазовые портреты, углы, состояния нейронов, мышц и афферентов. Явный запуск обучения находится под выключенным флагом `RUN_STUDY`. `results/current_joint.json`, если существует, выбирает новую совместную серию; иначе остаётся совместимость с прежним `results/best_genome.json`.

## Повторное обучение C: времена релаксации >5 мс

В `genome_cfg.json` для `muscles.flexor.tau_c`, `muscles.flexor.tau_1`, `muscles.extensor.tau_c` и `muscles.extensor.tau_1` установлен диапазон **[5,1; 100] мс**, логарифмическое кодирование. Значения 5 мс и ниже отклоняются при кодировании генома; крайние значения и мутация проверены тестом. В исходной библиотеке поля `tau_c` и `tau_1` хранят обратные величины (1/мс), но геном и аргументы конструктора задают времена в мс.

Предыдущая серия уже использовала нижнюю границу 5 мс. Её победитель `joint` имел времена 7,276; 19,739; 6,675; 23,041 мс (сгибатель τ_c, τ₁; разгибатель τ_c, τ₁), то есть уже выполнял строгое условие >5 мс. Поэтому пульсации силы нельзя объяснить нарушением этой границы. В уравнении `dF/dt = A·N·x − F/τ₁` время τ₁ влияет и на установившийся масштаб силы.

Повторная серия: оба метода, степени 2/3, 50 особей, вероятность мутации 0,1, seed ГА 43, 200 эпох на линию (4 обучения). Банк теста имеет новый seed 2026102223; обучение и валидация сохранены. Исходный геном B не изменён и допустим при новых границах. Это повторное обучение с новым seed, а не изолированная оценка эффекта изменения нижней границы на 0,1 мс.

Результаты сохраняются в [joint_sweep_tau_gt5_20261022](results/joint_sweep_tau_gt5_20261022/README.md). [Сравнение](results/joint_sweep_tau_gt5_20261022/relaxation_comparison/README.md) использует один новый тестовый банк для прежних и новых заранее выбранных победителей. На рисунке показаны последние 0,2 с сил без сглаживания; статистика сил вычисляется за последние 2 с. Полные фазовые сетки и осциллограммы сохраняются для обоих методов по прежнему протоколу.

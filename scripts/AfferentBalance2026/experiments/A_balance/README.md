# A_balance: баланс на всём диапазоне −50…+50°

[English](README.en.md) · [Все файлы результатов и функции тетрадки](../README.md) · [Модель](../MODEL_METHODS.md)

Два нейрона, две мышцы, полные Afferents. Нулевые задающие токи, никакого ПД/ПИД. Ограничение каждого нейромышечного веса: `0.0001 ≤ w ≤ 1`. Исходное значение — из `genome_cfg.json`; фиксированные `a1=0.2 м`, `a2=0.05 м` задаются там же. Шаг всегда 0,1 мс.

Учебные/валидационные/тестовые банки содержат 24/48/96 условий с независимыми фиксированными seed. Начальные углы охватывают весь диапазон −50…+50°, скорости −1…+1 рад/с, включая малые отклонения. Используется стратифицированная случайная выборка (Latin hypercube); в учебный банк дополнительно включены −50°, 0°, +50° при нулевой скорости. Импульсов нет. Банки A/B совпадают и остаются фиксированными в ходе обучения. Горизонт 10 с; критерий успеха и фитнесс описаны в общей модели.

Из корня репозитория:

```bash
.venv/bin/python scripts/AfferentBalance2026/experiments/A_balance/run_experiment.py --population 50 --generations 200 --workers 4
.venv/bin/python scripts/AfferentBalance2026/experiments/A_balance/run_sweep.py --workers 4
```

`--config` выбирает конфиг, `--output` — новый каталог; существующий каталог не перезаписывается. Остальные параметры одиночного запуска: `--seed`, `--mutation-probability`; серии: `--populations`, `--generations`, `--probabilities`, `--seeds`. Короткий `--duration` предназначен для технической проверки, не для научного сравнения.

В `explore_genome.ipynb` задайте `GENOME_PATH` для изучения обученного решения. Можно выбрать любую эпоху и особь по рейтингу, построить фазовую сетку, временные ряды и все переменные одного примера. По умолчанию загружается `results/best_genome.json`, если он уже создан; `GENOME_PATH=None` выбирает необученную конфигурацию. Текущая серия сохраняется в `results/sweep_20261021/`; итоговый обзор после анализа — `results/README.md`.

## Исправление момента натяжения, 26.10.2026

Текущая механика — `SpikingNN.Afferents/v3-tensile`: положительной силе натяжения соответствует `M = -F_flex*h_flex + F_ext*h_ext`. Сохранённый прежний победитель после исправления завершил **0/96** исходных тестовых эпизодов. Переобучение не выполнялось. Прежние оценки обучения ниже относятся к старому знаку. Перед запуском перезапустите ядро Jupyter и заново откройте обновлённую тетрадку. Старые выводы сохранены в `results/torque_sign_check_20261026/notebooks_before_correction/` и очищены в активных тетрадках.

## Диапазоны и локальные результаты

В `genome_cfg.json`, внутри `simulation`, задаются два простых диапазона. Они могут быть несимметричными; исключённого интервала около нуля больше нет.
```json
"initial_conditions": {
  "angle_range_deg": [-50.0, 50.0],
  "speed_range_rad_s": [-1.0, 1.0]
}
```
Реально выбранные точки сохраняются в `cases.npz` и показаны на `initial_conditions.png` внутри sweep. `results/` этого опыта содержит только его расчёты, всю историю поколений, лучшие геномы, полные траектории, тепловые карты и RMSE. Прежний скрипт обработки удалён при реорганизации; сохранённые результаты доступны в `results/`.

После завершения анализа:

- `results/initial_baseline.json` — исходный геном на тех же банках.
- `results/paired_comparison.csv` — сравнение A/B при одинаковых бюджетах.

RMSE геномов измеряет различие нормированных параметров, а не различие динамики или устойчивости. Сигналы одного примера строятся с полным шагом записи 0,1 мс; фазовые линии прореживаются только для отображения.

Папка `results/diagnostics_20261021/` перенесена в корзину по запросу пользователя. Геномы и история обучения сохранены; для новых траекторий используйте тетрадку. Журнал: `../B_balance/results/cleanup_diagnostics_20261021.json`.

# Структура экспериментов

[English](README.en.md)

```text
experiments/
  core/                     genome.py, fitness.py, evolution.py, run.py
  simulation.py             одна Numba-модель, проверка библиотекой, банки условий
  visualization.py          загрузка решений и общие графики
  A_balance/                run_experiment.py, run_sweep.py, genome_cfg.json
  B_balance/                run_experiment.py, run_sweep.py, genome_cfg.json
  C_setpoint_balance/       те же входные файлы, polynomial_study.py, joint_study.py
  D_trajectory/             controller.py, trajectory.py, run_experiment.py, run_sweep.py
```

В каждой папке опыта также находятся `README.md`, `README.en.md` и `explore_genome.ipynb`. Расчёты создают локальный `results/`. Нет вложенного `source/` и промежуточных цепочек импортов. В `core` нет функций закона задающих токов; общая физика находится в `simulation.py`, а законы токов — в C/D.

## Результаты A/B

| Файл внутри запуска | Содержание |
|---|---|
| `genome_cfg.json` | Полная конфигурация, включая английские описания 52 полей |
| `run.json`, `source_snapshot.zip` | Фактические параметры запуска, хеши и исходники |
| `cases.npz` | Учебные, валидационные, тестовые и демонстрационные условия |
| `generations/generation_XXXX.npz` | Вся популяция каждой эпохи, 50 (A) / 48 (B) нормированных и 52 физических параметра, метрики, состояние RNG |
| `history.csv`, `progress.json` | Сходимость и последняя завершённая эпоха |
| `final_population.npz` | Полная последняя популяция с учебными и валидационными оценками |
| `best_genome.json` | Победитель последней популяции по валидации, самодостаточная конфигурация |
| `validation_ranking.csv`, `test_metrics.csv`, `result.json` | Ранжирование, независимая проверка победителя, сводка |
| `best/rank_001/` … | Три лучших по валидации: `genome.json`, пять `case_XXX.npz`, `metrics.csv` |

Траектории лучших записываются с шагом 0,1 мс, включая начальное состояние: ±50°, ±25°, 0°, скорость 0. `columns` и `metric_columns` в NPZ задают значения столбцов. Записываются угол, скорость, потенциалы и переменные восстановления нейронов, спайки, синаптические токи, кальций, активация и силы мышц, шесть афферентных каналов, момент мышц. Падение также сохраняется, без продолжения после выхода за ±90°.

В A/B `run_sweep.py` использует размеры 10/30/50/100, постоянную вероятность мутации каждого свободного гена 0.1/0.3/0.6, seed 42, эпохи 30/60/100/150/200. Одна непрерывная линия обучения до 200 эпох на сочетание размера/вероятности/seed; ранние эпохи — контрольные точки той же линии, а не независимые короткие обучения. Сохраняются `checkpoints/epochs_XXX/`, `checkpoints.json`, общая `summary.csv`, тепловые карты и `genome_rmse.npz`. RMSE считается по нормированным свободным координатам (50 для A, 48 для текущего B); фиксированные параметры исключены. Один seed недостаточен для оценки статистической устойчивости.

## Тетрадки

По умолчанию загружается локальный `results/best_genome.json`, если он существует. `GENOME_PATH=None` означает исходный **необученный** геном. Можно указать путь к `best_genome.json`, `final_population.npz` или файлу эпохи; `RANK` выбирает особь. Для эпохи рейтинг учебный, для последней популяции — валидационный. Применяется сохранённая конфигурация решения.

`run_on_grid` считает сетку начальных условий, `phase_portrait` строит фазовый портрет, `view_states` показывает все группы переменных одного примера, `scan_parameter` исследует сетку значений свободного параметра. По умолчанию: 10×10 условий −50…50° и −1…1 рад/с; отдельные 10 временных рядов при нулевой скорости. Для обучения A/B нужно явно включить `RUN_TRAINING` или `RUN_SWEEP`; по умолчанию они выключены. В C совместное обучение включается флагом `RUN_STUDY`; по умолчанию он выключен.

## Серия от 21 октября 2026

A/B обучаются на всём прямоугольнике −50…50° × −1…1 рад/с, включая малые углы. Диапазоны задаются через `simulation.initial_conditions`. `results/sweep_20261021/` содержит 12 линий ГА и 60 контрольных точек каждого опыта. После анализа `results/best_genome.json` автоматически доступен тетрадке; Прежние папки диагностики перенесены в корзину по запросу пользователя. C использует выбранную сеть A и токи из конфига без обучения закона токов.

Серия завершена. Итоговые индексы: [A](A_balance/results/README.md), [B](B_balance/results/README.md), [C](C_setpoint_balance/results/README.md). Поздняя RMSE в сводках — средняя по эпизодам; падению присваивается штраф 90°, поэтому для B её нельзя интерпретировать как ошибку только успешно удержанных траекторий.


Текущий B использует `0.02 ≤ w < 0.1` и фиксированные `A=0.37` у обеих мышц. [Обработка B](../tools/select_sweep_winner.py) проверяет сохранённые поколения, выбирает максимум валидации и записывает 110 полных траекторий в `selected/` внутри серии:

```bash
.venv/bin/python scripts/AfferentBalance2026/tools/select_sweep_winner.py scripts/AfferentBalance2026/experiments/B_balance/results/sweep_restored_weights_A037_20261021
```

Команда рассчитана на завершённую серию и новый `selected/`; предыдущий выбор сохраняется внутри исходной серии.

## C: совместное обучение сети и задания, 22 октября 2026

Общий блок контроллера по-прежнему содержит 52 поля. В C оба мышечных A фиксированы на 0,37, остаются 48 свободных параметров контроллера. Кубические функции токов добавляют восемь генов: 60 физических полей / 56 свободных координат. Квадратичный вариант: 58/54; таблица для пяти целей: 62/58. В `joint_study.py` находятся режимы `joint` и `staged` (таблица → ограниченный МНК → совместное дообучение). Общие генетические операторы и фитнесс переиспользуются из core; закон токов остаётся в C.

Каждая особь в каждой эпохе оценивается на пяти целях. Банки обучения/валидации/теста содержат 40/108/408 эпизодов; тестируется только общий победитель по валидации. `best_genome.json` сохраняет объединённую схему, `best_controller.json` — совместимый блок из 52 полей, `current_law.json` — функцию задания. Каждое поколение содержит оба блока генов. Тетрадка C читает `results/current_joint.json`, включая явную пометку пилота. Команды и карта файлов — в [документации C](C_setpoint_balance/README.md). Прежняя серия C с нулевыми токами выше остаётся историческим контролем. Новый пилот на 20 особях и 30 эпохах дал 76/408 успешных тестов; весь диапазон целей пока не освоен.

Новая полная серия C: [joint_sweep_20261022](C_setpoint_balance/results/joint_sweep_20261022/README.md), 16 × 200 epochs.

Повторное обучение C с τ_c, τ₁ ≥5,1 мс: [протокол и результаты](C_setpoint_balance/results/joint_sweep_tau_gt5_20261022/README.md), 4 × 200 эпох, seed 43. Пульсации силы сохраняются.

## D: непрерывное слежение, 23 октября 2026

[Документация и API](D_trajectory/README.md), [тетрадка](D_trajectory/explore_genome.ipynb).
Общий Numba-шаг физики в `simulation.py` используется как эпизодным решателем, так и потоковым `AngleController`. Класс принимает угол −45…45°, сохраняет все состояния и возвращает фактическое движение. D отдельно содержит сигналы, фильтр токов и оценку слежения. В core не добавлена логика траекторий.

Серия: четыре сохранённых C × три времени фильтра, затем 30 особей × 80 эпох для `command_only` и `joint`. Банки 8/10/18, независимая диагностика 3 амплитуды × 3 периода. Сохраняются все поколения и полная динамика 0,1 мс. D имеет отдельный критерий успеха относительно движущейся цели; его нельзя отождествлять со статической успеваемостью A/B/C.

# Структура экспериментов

[English](README.en.md)

```text
experiments/
  core/                     genome.py, fitness.py, evolution.py, run.py
  simulation.py             одна Numba-модель, проверка библиотекой, банки условий
  visualization.py          загрузка решений и общие графики
  A_balance/                run_experiment.py, run_sweep.py, genome_cfg.json
  B_balance/                run_experiment.py, run_sweep.py, genome_cfg.json
  C_setpoint_balance/       те же входные файлы, polynomial_study.py
```

В каждой папке опыта также находятся `README.md`, `README.en.md` и `explore_genome.ipynb`. Расчёты создают локальный `results/`. Нет вложенного `source/` и промежуточных цепочек импортов. В `core` нет функций закона задающих токов; общая физика находится в `simulation.py`, а токи — в C.

## Результаты A/B

| Файл внутри запуска | Содержание |
|---|---|
| `genome_cfg.json` | Полная конфигурация, включая английские описания 52 полей |
| `run.json`, `source_snapshot.zip` | Фактические параметры запуска, хеши и исходники |
| `cases.npz` | Учебные, валидационные, тестовые и демонстрационные условия |
| `generations/generation_XXXX.npz` | Вся популяция каждой эпохи, 50 нормированных и 52 физических параметра, метрики, состояние RNG |
| `history.csv`, `progress.json` | Сходимость и последняя завершённая эпоха |
| `final_population.npz` | Полная последняя популяция с учебными и валидационными оценками |
| `best_genome.json` | Победитель последней популяции по валидации, самодостаточная конфигурация |
| `validation_ranking.csv`, `test_metrics.csv`, `result.json` | Ранжирование, независимая проверка победителя, сводка |
| `best/rank_001/` … | Три лучших по валидации: `genome.json`, пять `case_XXX.npz`, `metrics.csv` |

Траектории лучших записываются с шагом 0,1 мс, включая начальное состояние: ±50°, ±25°, 0°, скорость 0. `columns` и `metric_columns` в NPZ задают значения столбцов. Записываются угол, скорость, потенциалы и переменные восстановления нейронов, спайки, синаптические токи, кальций, активация и силы мышц, шесть афферентных каналов, момент мышц. Падение также сохраняется, без продолжения после выхода за ±90°.

`run_sweep.py` использует размеры 10/30/50/100, постоянную вероятность мутации каждого свободного гена 0.1/0.3/0.6, seed 42, эпохи 30/60/100/150/200. Одна непрерывная линия обучения до 200 эпох на сочетание размера/вероятности/seed; ранние эпохи — контрольные точки той же линии, а не независимые короткие обучения. Сохраняются `checkpoints/epochs_XXX/`, `checkpoints.json`, общая `summary.csv`, тепловые карты и `genome_rmse.npz`. RMSE считается по 50 нормированным свободным координатам; фиксированная геометрия исключена. Один seed недостаточен для оценки статистической устойчивости.

## Тетрадки

По умолчанию загружается локальный `results/best_genome.json`, если он существует. `GENOME_PATH=None` означает исходный **необученный** геном. Можно указать путь к `best_genome.json`, `final_population.npz` или файлу эпохи; `RANK` выбирает особь. Для эпохи рейтинг учебный, для последней популяции — валидационный. Применяется сохранённая конфигурация решения.

`run_on_grid` считает сетку начальных условий, `phase_portrait` строит фазовый портрет, `view_states` показывает все группы переменных одного примера, `scan_parameter` исследует сетку значений свободного параметра. По умолчанию: 10×10 условий −50…50° и −1…1 рад/с; отдельные 10 временных рядов при нулевой скорости. Для обучения A/B нужно явно включить `RUN_TRAINING` или `RUN_SWEEP`; по умолчанию они выключены. C запускает только повторные симуляции.

## Серия от 21 октября 2026

A/B обучаются на всём прямоугольнике −50…50° × −1…1 рад/с, включая малые углы. Диапазоны задаются через `simulation.initial_conditions`. `results/sweep_20261021/` содержит 12 линий ГА и 60 контрольных точек каждого опыта. После анализа `results/best_genome.json` автоматически доступен тетрадке; `results/diagnostics_20261021/` содержит независимую фазовую сетку. C использует выбранную сеть A и токи из конфига без обучения закона токов.

Серия завершена. Итоговые индексы: [A](A_balance/results/README.md), [B](B_balance/results/README.md), [C](C_setpoint_balance/results/README.md). Поздняя RMSE в сводках — средняя по эпизодам; падению присваивается штраф 90°, поэтому для B её нельзя интерпретировать как ошибку только успешно удержанных траекторий.


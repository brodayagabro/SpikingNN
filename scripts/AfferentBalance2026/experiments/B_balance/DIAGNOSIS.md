# Почему B даёт 38–40%: сравнение 21 октября 2026

> Историческая диагностика до изменения протокола. Её папки результатов перенесены в корзину по запросу пользователя; пути ниже описывают прежнее расположение. Журнал: `results/cleanup_diagnostics_20261021.json`. Текущий B имеет `0.02 ≤ w < 0.1` и фиксированные `A=0.37`; оценки ниже относятся к прежним геномам.

[English](DIAGNOSIS.en.md) · [Опыт B](README.md)

Нынешние запуски B нашли слабые, односторонние решения. Хороший контроллер существует внутри исходного домена `0.0001 ≤ w ≤ 0.02`: перенос лучшего A с согласованным изменением `w` и `k` дал 96/96 независимых тестов и 100/100 точек фазовой сетки. Это диагностический перенос готовой сети, **не новое обучение B**. Исходные результаты обучения и выбранные геномы не заменялись.

Успех означает вход в полосу ±3°, ±0.35 рад/с не позже 3 с и сохранение её до конца эпизода. Новые test и phase-grid не использовались для дообучения; выводы ограничены этими конечными банками и выбранными контроллерами.


Ваши 38/100 относятся к отдельному запуску тетрадки. На момент проверки `GENOME_PATH` указывал на `results/notebook_run_20261021_2024/best_genome.json`, а не на `results/best_genome.json` из общего sweep. У обоих новых контроллеров все 50 запусков с положительным начальным углом неуспешны; при отрицательном угле успех составляет 38/50 и 40/50 соответственно.

Около 75% начальной популяции строится около исходного генома, остальные особи равномерны в нормированных координатах. Для логарифмического `w` медиана равномерной части изменилась с 0.04472 до 0.001414 — примерно в 31.6 раза. Исходное значение уменьшено в 8 раз. Это заметно изменило старт и геометрию поиска, хотя сетка размеров популяции, вероятностей мутации и формула fitness остались прежними. Насколько каждый фактор влияет на частоту сходимости, потребует отдельных повторов с разными seed.

## Какие параметры неудачны

| Контроллер | `w_F` / `w_E` | `k_F` / `k_E` | Максимальная сила F / E, Н |
|---|---|---|---|
| Старый | 0.05024 / 0.07700 | 0.79563 / 0.68560 | 15.30 / 9.08 |
| B из sweep | 0.01713 / 0.00777 | 0.55384 / 0.36503 | 11.51 / 21.30 |
| B из тетрадки | 0.00328 / 0.00443 | 0.47388 / 0.45550 | **0.563 / 16.36** |
| A после переноса в B | 0.02000 / 0.02000 | 0.19981 / 0.12880 | 62.48 / 41.36 |

Из уравнения `dF/dt = A N x − F/τ₁`, где `0 ≤ x ≤ 1`, следует верхняя граница силы при нулевой исходной силе: `F ≤ A N τ₁`. У сгибателя из тетрадки `N=7.72178`, `A=0.00461702`, `τ₁=15.80415 мс`: даже при насыщении сила не превышает 0.56344 Н. При +50° и нулевой скорости для компенсации тяжести одним сгибателем требуется **8.67332 Н**. У этого генома даже идеальная мгновенная активация сгибателя при выключенном разгибателе даёт статический предел всего около +3.596°. Это ограничение данного генома, а не всего пространства B.

У лучшего B из sweep номинальной силы больше, но существенно отличаются обратные связи, перекрёстные проекции P и времена активации. Его максимальная сила сама по себе не объясняет всю динамическую неудачу. Отдельные контролируемые вмешательства здесь: обрезание только `w` и согласованное изменение `w/k`; полный список 52 параметров сохранён в `parameters.csv`.

## Почему допустим перенос из A

Модель использует

$$
\dot C = w u - C/\tau_c,\qquad x = \frac{C^m}{C^m+k^m}.
$$

При `C(0)=0` замена `w′=s w`, `k′=s k` даёт `C′=s C`, сохраняя `x`. Поэтому в точной арифметике сохраняются сила, афферентные сигналы, нейронная и механическая динамика; меняется только масштаб кальция. Для каждого мускула лучшего A использовано `s=0.02/w`. Полученные `k=0.1998051072` и `0.1288020123` входят в разрешённый диапазон `[0.1,2]`; все остальные 48 поля оставлены прежними. Проверены все ограничения B, включая фиксированную геометрию.

Численные траектории после преобразования могут слегка различаться из-за округления и пороговых спайков. Поздняя RMSE перенесённого A на новой сетке — 0.01816°, на новом тесте — 0.01847°; успех сохраняется на всех проверенных условиях. Простое обрезание его весов тоже дало 100/100 на сетке, но с RMSE 0.516° и 43/48 на старом тесте с толчками, поэтому это другое вмешательство.

Таким образом, при свободных `k`, `P`, `A`, `N`, `τ₁` малый `w` сам по себе не означает слабый привод. Для следующего обучения полезно использовать допустимый перенос как начальную особь, либо искать отношение `w/k` и применять согласованные мутации. Для исследования именно ослабления нейромышечной передачи следует явно определить, какие компенсирующие параметры остаются свободными. Расширение верхней границы `w` не требуется для существования хорошего решения в нынешнем домене.

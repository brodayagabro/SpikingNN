# B_balance: баланс с больших отклонений

[English](README.en.md) · [Структура результатов и тетрадки](../README.md) · [Модель](../MODEL_METHODS.md)

Два нейрона, две мышцы, полные нелинейные Afferents. Задающие токи нулевые, ПД/ПИД отсутствует. Шаг 0,1 мс; момент мышц без множителя ×10.

В текущем `genome_cfg.json` восстановлен исторический диапазон нейромышечного веса **`0.02 ≤ w < 0.1`** у обеих мышц, начальное значение **0.08**. Верхняя граница записана как ближайшее число float ниже 0.1. По указанию пользователя физиологический параметр **`A=0.37 N/ms`** фиксирован у обеих мышц. `A`, `a1=0.2 м` и `a2=0.05 м` входят в сохраняемый геном, но не изменяются генетическими операциями. Всего 52 физических поля и **48 свободных координат**. Описания полей и соответствия модели написаны по-английски.

Обучение, валидация и независимый тест используют 24/48/96 условий из всего прямоугольника **−50…+50° × −1…+1 рад/с**, включая малые отклонения. Банки сформированы независимыми фиксированными seed через Latin hypercube. В обучение добавлены −50°, 0°, +50° при нулевой скорости; импульсов нет. Банки совпадают с A и не меняются в ходе обучения. Горизонт каждого эпизода 10 с.

Диапазоны задаются в `simulation.initial_conditions`:

```json
"initial_conditions": {
  "angle_range_deg": [-50.0, 50.0],
  "speed_range_rad_s": [-1.0, 1.0]
}
```

## Запуск и выбор решения

Из корня репозитория:

```bash
.venv/bin/python scripts/AfferentBalance2026/experiments/B_balance/run_experiment.py --population 50 --generations 200 --workers 16
.venv/bin/python scripts/AfferentBalance2026/experiments/B_balance/run_sweep.py --workers 16 --output scripts/AfferentBalance2026/experiments/B_balance/results/sweep_restored_weights_A037_20261021
.venv/bin/python scripts/AfferentBalance2026/tools/select_sweep_winner.py scripts/AfferentBalance2026/experiments/B_balance/results/sweep_restored_weights_A037_20261021
```

Первые две команды — альтернативные способы обучения: один запуск или полная серия. Третья обрабатывает завершённую серию; существующий `selected/` не перезаписывается. Для повторения задайте новый `--output`. `--config` выбирает конфиг. Одиночный запуск поддерживает `--seed`, `--mutation-probability`; серия — `--populations`, `--generations`, `--probabilities`, `--seeds`. Сокращённый `--duration` подходит только для технических проверок.

Полная серия: популяции 10/30/50/100, постоянная вероятность мутации каждого свободного гена 0.1/0.3/0.6, seed 42. Это 12 независимых запусков по 200 эпох с контрольными точками 30/60/100/150/200. Обучение начинается с новой популяции; перенесённый геном A не используется. Победитель каждой контрольной точки выбирается по валидации последней популяции, победитель всей серии — по максимуму этой же валидационной оценки. Тестовые результаты и фазовая сетка не участвуют в отборе.

## Результат повторного обучения

Завершены все 12 линий и 60 контрольных точек. Победитель по валидации: **50 особей, мутация 0.1, эпоха 200, seed 42**. Независимый тест: **96/96**, средняя поздняя RMSE **0.004013°**. Фазовая сетка: **100/100**; нулевая скорость: **10/10**. Веса сгибателя/разгибателя: **0.0493838 / 0.0528917**; оба A строго **0.37**. Аудит всех 2400 поколений прошёл.

На 110 проверенных траекториях максимум абсолютной скорости составил **14.699 рад/с**, пиковые силы мышц — **114.833 / 87.438 Н**. Успешное удержание равновесия не устанавливает физиологическую реалистичность этих переходных процессов. Измерения и проверка целостности файлов находятся в `selected/trace_audit.json`; сверка с библиотечной моделью — в `selected/model_reference_check.json`.

## Где искать результаты

Всё находится в локальном `results/`; данные исключены из Git.

- `best_genome.json` — итоговый геном с конфигурацией, английскими описаниями полей и происхождением.
- `current.json`, `summary.json`, `README.md` / `README.en.md` — указатель на актуальную серию, оценки и обзор.
- `sweep_restored_weights_A037_20261021/summary.csv` — все 60 контрольных точек; рядом тепловые карты и `genome_rmse.npz` / PNG / PDF.
- `population_*/mutation_*/seed_*/` внутри серии — вся история 200 популяций, исходники и хеши, банки условий, три лучших генома и их динамика для каждой контрольной точки.
- `selected/` внутри серии — победитель, повторный независимый тест, аудит всех поколений, `phase.png/pdf`, `angles.png/pdf`, графики `limb`, `neurons`, `muscles`, `afferents`.
- `selected/traces/` — 100 фазовых траекторий на сетке 10 углов −50…+50° × 10 скоростей −1…+1 рад/с и ещё 10 траекторий при нулевой скорости. Все состояния записаны с шагом 0,1 мс. Сигналы отдельных подсистем показаны для одного примера: −27,78°, скорость 0.

В `explore_genome.ipynb` задайте `GENOME_PATH`: итоговый геном, последнюю популяцию или файл любой эпохи. `RANK` выбирает особь, `run_on_grid` считает сетку, `phase_portrait` и `view_states` показывают динамику; `scan_parameter` меняет свободный параметр. Фиксированный A нельзя менять через эту функцию — требуется отдельная конфигурация. `GENOME_PATH=None` выбирает необученный геном. Для повторного обучения явно включите `RUN_TRAINING` или `RUN_SWEEP`.

RMSE геномов считается по 48 нормированным свободным координатам; он не измеряет различие динамики. Фазовые линии прореживаются только для отображения. Один seed и конечная сетка не доказывают глобальную устойчивость.

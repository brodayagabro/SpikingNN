# Актуальный научный отчёт

[PDF](REPORT.pdf) · [Статья на русском](REPORT.md) · [English article](REPORT.en.md) · [Полный геном](APPENDIX_PARAMETERS.md)

Отчёт посвящён исправленной механике натяжения, полным нелинейным Afferents и переобучению A–D от 26 октября 2026 года. Включены все уравнения, шаги генетического алгоритма, условные аналитические оценки устойчивости, независимые тесты, фазовые сетки, сигналы нейронов, мышц и афферентов, точные команды и смысл ключей. В основной серии мышечное A фиксировано на 0,37 во всех опытах.

Два рисунка симметричной серии показывают удержание +45° на сетке начальных условий и первый отложенный пример следования синусоиде. В каждом есть фазовые траектории, углы, потенциалы нейронов, силы мышц, афференты и токи. Для C отдельно указаны различия успеха по целям; для D — сохранённое нарушение строгого критерия. Рисунки используют реальные сохранённые расчёты, а не схематические траектории.

Научный текст находится в `article_body.ru.txt` и `article_body.en.txt`. Сборщик `build_retraining_article.py` вставляет проверенные таблицы и рисунки завершённых запусков. `build_pdf.py` верстает русскую статью с полным приложением генома. `refresh_report.py` направляет обновление к актуальному сборщику. Вычисленные файлы находятся в `results/muscle_tau50_20261026/`, где `manifest.json` содержит выбранные запуски и хеши. Его блок `mirror_symmetry` фиксирует отдельные симметричные решения, сравнительный JSON, исходные метрики и файлы двух рисунков; сводка находится в `results/mirror_symmetry_20261026/comparison.json`. В `previous_report/` сохранён прежний отчёт. Исторические рисунки из других каталогов не подтверждают результаты исправленной модели.

Запуск из корня репозитория:

```bash
.venv/bin/python scripts/AfferentBalance2026/report/build_retraining_article.py
.venv/bin/python scripts/AfferentBalance2026/report/build_pdf.py \
  --pandoc /home/nickolai/miniconda3/envs/CPG/bin/pandoc
```

Команды обучения и построения фазовых рисунков подробно описаны в разделе 7 статьи. Обновление статьи не запускает обучение. `--allow-incomplete` предназначен только для черновой проверки и не используется в итоговом отчёте.

В текущей серии у обеих мышц tau_c ∈ [50,100] мс и tau_1 ∈ [50,200] мс. Прежние победители остаются в `results/tensile_retrain_20261026/` каждого опыта; предыдущий отчёт сохранён в `results/muscle_tau50_20261026/previous_report/`. Сравнительная таблица отдельно показывает старую и новую области поиска.

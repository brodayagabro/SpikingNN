# AfferentBalance2026

[English](README.en.md)

**Исходники к статье:** [topubsrc/README.md](topubsrc/README.md) — самостоятельный комплект
экспериментов A–C без зависимости от SpikingNN: восемь Python-файлов, конфигурации,
сохранённые геномы и три ноутбука. Для запуска достаточно этой папки.

**Новая серия от 16 ноября 2026:** перекрёстные выходы `P.0.1` и `P.1.0` ограничены строго ниже 0,1. Прежние публикационные результаты удалены. Fitness сохранён; активность обоих нейронов измеряется отдельно. Команды и обновляемые таблицы — в [topubsrc/README.md](topubsrc/README.md).

Локальные эксперименты со спайковым регулятором, двумя мышцами-антагонистами и полными нелинейными
`SpikingNN.core.Izh_net.Afferents`. Шаг 0,1 мс; мышечные силы направлены вдоль натяжения.
ПД/ПИД-регулятора и множителя момента ×10 нет.

| Опыт | Постановка |
|---|---|
| A_balance | Верхнее равновесие, нулевые токи, w ≤ 1 |
| B_balance | То же, 0,02 ≤ w < 0,1 |
| C_setpoint_balance | Постоянные цели −45…45°: совместный поиск сети и полинома либо таблица → МНК → полином |
| D_trajectory | Непрерывное слежение: joint, command_only и сравнение с frozen |

Исходные presets фиксируют A=0,37, τc=50…100 мс, τ1=50…200 мс. У контроллера 52 физических поля;
число независимых координат вычисляется из фиксированных параметров и зеркальных связей.

Из корня репозитория:

```bash
.venv/bin/python scripts/AfferentBalance2026/run.py validate --config scripts/AfferentBalance2026/configs/studies/A_smoke.json --json
.venv/bin/python scripts/AfferentBalance2026/run.py train --config scripts/AfferentBalance2026/configs/studies/A_smoke.json
```

Это короткая техническая проверка, а не научное обучение. Новый результат появится в `results/smoke_A`;
для повторения укажите новый `--output`. Старые результаты не переносятся и не перезаписываются.

`solution.json` — выбранная особь; последняя популяция хранится отдельно. Только `publish` обновляет указатель текущего решения.
Тетрадки показывают выбранный источник и его параметры, обучение по умолчанию выключено.
Большая сеть или MultyLimbSystem потребуют нового кодека и проверенного численного адаптера;
конфигурация текущей схемы намеренно не позволяет менять смысл 52 полей.
